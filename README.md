# Speed converter

A React application that converts speed and pace from one unit to other units. 
Currently available units are:
- kilometers per hour
- miles per hour
- metres per second
- minutes per kilometer
- minutes per mile

Give input speed in any of these units and it will be converted to all the other units.

### How to run the application locally

- Make sure you have Git and Node installed
- Clone the project to your local repository using the following command:
```
git clone git@github.com:helmiikonen/speed-converter.git
```
- Navigate to the root directory of the project and type the following commands:
```
npm install
npm run dev
```
- Open your browser at ```localhost:5173```
